# Kabbalah

[Play](https://royschwartz.github.io/kabbalah-landscape-study/)

Click or tap the opening screen to advance one line at a time through a short HyperCard-style pixel dissolve. Town passages also appear one sentence at a time. There is no visible Continue button. The complete game view remains, surrounded by black, with Roy’s travel drawing below it at the bottom right. Up/down walk forward/back; left/right turn. The centre and red corner marks have no actions. Other on-screen game actions are temporarily removed while Roy chooses which to restore.

Hold travel to increase stride distance through ×1, ×2, ×3, ×4 and ×5, staying at ×5. Held turns use ×1, ×2 and ×3. After a completed movement, release adds one final ×1 movement. Keyboard arrows/WASD still walk and turn; Q/E sidestep. Drag the view sideways and release to turn freely. The existing world, lighting, grey smoke, clock rules and saved progress remain unchanged.

This repository contains only the public playable build.
